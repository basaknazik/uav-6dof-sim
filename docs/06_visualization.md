# Phase 6 — Visualisation & polish

`sim/visualize.py` (matplotlib only):
* `plot_trajectory_3d` — East/North/Altitude path with a ground shadow and airframe glyphs along it. The vertical axis is stretched
  (default 8x) because altitude changes are tiny compared with the ground track; glyphs are compensated (`z_scale = 1/zf`) so the airframe is not distorted.
* `make_animation` — two-panel GIF (flight path + attitude view with roll/pitch/yaw readout), exported with Pillow.
* `aircraft_lines` — the airframe drawing: body-frame segments rotated with `R_b→v = (R_v→b)ᵀ`, then mapped from NED to plot axes (E, N, Up = −D).

All frame conventions are tested (tests/test_visualize.py): level northbound → nose to +N, right wing to +E, fin up; yaw 90° → nose East;
pitch up raises the nose; roll right drops the right wing; the glyph's nose equals the body x-axis from the rotation matrix for random attitudes;
altitude = −pd; z_scale affects only the vertical extent; the animation file is a valid GIF with the expected frame count.

Everything is regenerated by `python scripts/make_figures.py`; the README collects the results, equations, design choices and limitations.
